Práctica 2 Menu


















Objetivo y proposito



Objetivo de la práctica


  1. Investigar e implementar tecnologías de diseño web
    1. Analizar el uso de Bootstrap como framework de diseño.
    2. Estudiar la distribución de elementos mediante CSS externo.
  2. Desarrollar un sitio web con diseño de layout estructurado
    1. Crear una estructura base utilizando divisiones <div> y <span>.
    2. Implementar secciones obligatorias: contenedor, header, sidebar, content y footer.
    3. Garantizar la uniformidad de presentación en todo el sitio mediante una hoja de estilos CSS.



Propósito de la práctica


  • Construcción de un sitio web en equipo
    • Crear un conjunto de páginas web simples, estáticas y enlazadas (mínimo 5 archivos .html y 1 archivo .css).
    • Diseñar una página principal de presentación y una dedicada al objetivo/propósito.
    • Diseñar la página personal actualizada de cada integrante del equipo.
  • Aplicación de elementos de contenido HTML y formato
    • Incluir párrafos, al menos dos niveles de encabezados, texto en negritas y cursivas.
    • Implementar tablas con formato desde CSS, líneas horizontales y citas (quotes).
    • Asegurar la navegación y el mapa de sitio funcional mediante hipervínculos.
